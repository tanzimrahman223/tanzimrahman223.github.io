# Tanzim Rahman — Portfolio

Electrical engineering student at UC San Diego, interested in robotics. Expected graduation: 2028.

## Website

Static HTML, CSS, and JavaScript. Open index.html locally, or host this repository using GitHub Pages.

## GitHub Pages

In Settings > Pages, select Deploy from a branch, then main and /(root). Save. GitHub will display the live URL when deployment completes.

## Editing

Edit app.js for project, skills, about, and contact content. Edit style.css for the design. Tanzim-Rahman-Resume.pdf is the downloadable original resume; its graduation date still states June 2029, while the website uses the owner-confirmed 2028.

Project illustrations are conceptual. Actual photos, demos, and project-specific repository links can be added later.
